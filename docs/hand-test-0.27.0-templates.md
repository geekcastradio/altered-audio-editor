# Hand test: starter session templates (0.27.0)

1. Start the app with a fresh config folder, or delete the `templates` folder in the app's config folder first. Open File > New Session.
2. The Template list holds Two-Host Show, Solo Voiceover and Audiobook. Pick Two-Host Show: the note shows 4 tracks and 48 kHz.
3. Create the session. Host and Guest are mono and in the foreground, Music is marked as ducked, and the tracks have colors.
4. Pick Audiobook: it is 44.1 kHz with Narration and Room Tone.
5. Delete one starter with the trash button, close and reopen the app, then open New Session again. The deleted one stays gone and the other two are still there.
6. Make your own template with File > Save as Session Template. It sits in the list beside the starters.
7. Upgrade case: if you already have templates of your own, the starters are added beside them and nothing of yours changes.
