# Altered Audio Editor 0.27.0

Work in progress. This file grows as 0.27.0 gets built.

## What's new

- **Dialogs look and act alike.** Time Stretch, Fit Music to Length, Add Tracks, Generate, Recording Options, File Tags, New Audio File, the rename box, Pitch, Match EQ, Auto Mic Mix, Sync Tracks, Export Markers and the clip color picker now share one dialog design: Cancel on the left and the main action last in the accent color, the cursor already in the first field, Enter to apply, Escape to close, and a dim button says why it is dim. In Match EQ, Auto Mic Mix and Sync Tracks the colored button is now the action, not Close. More dialogs follow in later builds of this release.
