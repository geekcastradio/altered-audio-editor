# Hand test for 0.60.0

Nothing user-facing should change. A short pass is enough.

1. Open a saved session. Tracks, clips and markers look the same as in 0.59.0.
2. Add markers of each kind, rename one, change its color. Export chapters as a file and embedded in an MP3.
3. Open a Voice Chain with Curve EQ and Phase Rotate; drag points. Split a band set with the Frequency Band Splitter.
4. Import files into the Files panel. Sort by each column and search. Durations and sizes read correctly.
5. Draw volume and pan automation, snap points, move several at once.
6. Open Libraries, switch between grouping by bin, type and flat list; fold a section; sort by name and date.
7. Run Match EQ and the Publish Package check on a short episode.
8. Check the update notice and Help > Check for Updates still work.
