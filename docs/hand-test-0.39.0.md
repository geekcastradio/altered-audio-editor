# Hand test 0.39.0

Part 1: Audition's keys. Press each key and check the result. Nothing here needs a file open unless noted.

## Panel keys (Window menu should show the same keys)
1. Alt+1 Editor, Alt+2 Mixer, Alt+3 Properties, Alt+5 Loudness Match, Alt+6 Time Info, Alt+7 Levels, Alt+8 Markers, Alt+9 Files, Ctrl+P Metadata, Alt+X Phase Wheel. Each opens or focuses its panel.
2. Our own panels: Alt+0 Voice Chain, Alt+4 Sound Types, Ctrl+Alt+1 Audio FX, Ctrl+Alt+2 Libraries, Ctrl+Alt+3 History.
3. Window > each of those panels shows the key next to its name, and no key is shown twice.

## Function keys
4. F1 opens the User Guide. F2 repeats the last command with its dialog, F3 without. F4 opens Settings. F9 shows or hides the spectral view. F10 turns Meter Input Signal on and off. F11 opens Convert Sample Type. F12 swaps between the Multitrack and the Waveform Editor.
5. Press Alt+K, search for F9: it should list Toggle Spectrum, and Add Retake Marker should now say F6.

## Markers and other keys (open a session or a file)
6. F6, Shift+F6 and Ctrl+F6 drop Retake, Cut This and Great Bit markers. F8 and M still drop a cue marker, Shift+F8 a CD track marker, Ctrl+Shift+F8 a range marker.
7. Select a marker in the Markers panel: Ctrl+0 deletes it, "/" renames it. Ctrl+Alt+0 deletes all markers (check it asks or can be undone).
8. Ctrl+Shift+A deselects all. Ctrl+Shift+K and Ctrl+Alt+K open Settings. Alt+Z opens Frequency Analysis. Ctrl+M minimizes the window. "+" and "-" zoom in and out.
9. Ctrl+Alt+U runs Fill Single Click (it moved from Ctrl+Alt+K). Ctrl+- no longer zooms out.

## Audition import
10. Edit > Keyboard Shortcuts > import your Audition export. The notice should list fewer unmatched commands than before, and Alt+1..9 should stay as they are afterwards.

Anything that does not work, send me the key, what happened and what you expected.
