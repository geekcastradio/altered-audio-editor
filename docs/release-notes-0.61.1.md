# Altered Audio Editor 0.61.1

A small update after 0.61.0.

## New

- Help > Ask a Question or Share an Idea... opens the project's GitHub Discussions page in your browser. Questions and ideas go there, bugs stay in Issues.

## Fixed

- The macOS Apple silicon build was missing from 0.61.0 because its disk image step failed once on the build machine. The macOS builds now retry that step. If you are on an Apple silicon Mac, this is the first release with a build for you since 0.60.0. If it is missing again, the release page will say so.

## Notes

- No new settings or shortcuts. Nothing else changes. The 0.61.0 notes still apply.
- Free, GPLv3, no telemetry.
