## Altered Audio Editor 0.19.0

Markers get a real right-click menu and a roomier panel, the Files panel scrolls sideways, and imported sessions show up in Open Recent.

### Markers
- **Right-click a marker flag on the ruler, or a row in the Markers panel.** The menu has Go to Marker, Show in Markers Panel, Rename, Insert into Playlist, Convert to Range (or back to a point), Change Marker Type and Delete. Convert to Range stretches a point to the end of your time selection, or five seconds when there is none.
- **Click a flag on the ruler to pick it.** The Markers panel scrolls to that marker.
- **A bigger Markers panel.** New End and Description columns (Description replaces the Notes line), a search box that filters by name, description or type, drag the edge of any column heading to resize it, and the table scrolls sideways when it is wider than the panel.

### Files panel
- **Drag a column heading's edge to resize it.** Columns no longer disappear when the panel is narrow; scroll sideways instead.

### Sessions
- **Imported .sesx sessions appear in Open Recent.** Choosing one imports it again as a new session.

### Editing
- **The Razor line runs through every lane.** The track a click would cut is drawn stronger.
