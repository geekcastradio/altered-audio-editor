# Hand test: 0.54.0

- Batch Convert: open the Chain picker. The new starters are listed (peak levels, fades, hard limit, voice-over compressor, de-ess, noise, hiss, room echo, 60 Hz hum, vocal removal, DC offset, telephone, pitch). Run two or three on a short file and listen: each does what its name says. The de-ess pick is a new preset set by ear for the first time, so say if it is too strong or too weak.
- QuickPass: with six starting tracks and audio on only two, the Tracks menu lists two entries. With audio on one track, the Tracks button is gone. Scanning still works.
- Speaker Balance (Multitrack menu) on a session with two or more voice tracks: same notice and same gain changes as 0.53.0.
- File Tags dialog and Metadata panel: edit tags on a WAV, FLAC, MP3 and M4A file and save; blank fields still clear tags, and an OGG file still shows as not supported.
- New session, import several files: track names come from the file names as before (a leading speaker number and the extension are dropped).
- Type a letter in a list or menu (for example the Chain picker's list or a right-click menu): it jumps to the matching row.
- Open a session, play it, edit a clip, save, close and reopen: nothing different from 0.53.0.
