## Altered Audio Editor 0.20.1

A small fix for the Waveform editor's recording input.

### Recording
- **Settings > Audio Devices now lists every input for the Waveform editor.** The "Waveform editor records from" menu could show only System default input while the multitrack input menus listed everything. Devices that share a name, such as two outputs offered as System audio, are now listed once, and the menu no longer depends on every name being different.
