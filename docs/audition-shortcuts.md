# Audition keyboard shortcuts compared with ours

Source: the project lead's exported Audition 26.5 shortcut file (2026-10-29). Audition's own key numbers for function keys are not documented, so F-key entries other than F8 (Add Cue Marker) were left out until confirmed.

## Already matched
Waveform and Multitrack views (9, 0, 1), zoom in and out (=, -), Zoom to Session (\\), Select All, Space (play and stop), Shift+Space (record), Shift+X (return to start on stop), Delete, Shift+Backspace (ripple delete), Undo, Ctrl+Y, Cut, Copy, Paste, Repeat Last Command (Ctrl+R, Shift+R), New Session, Open, Close (Ctrl+W), Save, Home and End, Add Cue Marker (M, Shift+8), Add Cart Marker (C), Add Stereo and Bus Track (Alt+A, Alt+B), Delete Track, Split (Ctrl+K), Nudge (Alt+, Alt+.), Nudge to track above and below (Alt+Up, Alt+Down), Group and Suspend Grouping, Select Clips to End of Track, Select Next Clip, Add Tracks, Delete Empty Tracks, Capture Noise Print (Shift+P), Spectral display (Shift+D), Convert Sample Type (Shift+T), Meter Input (Alt+I), vertical zoom (Alt+=, Alt+-), HUD (Shift+U), Hide Effect Windows, tools V R Y T, Clear Time Selection (G), Next and Previous Marker (Ctrl+Alt+Left and Right), Next and Previous File (Ctrl+Tab, Ctrl+Shift+Tab).

## Added to match Audition (2026-10-29)
Deselect All (Ctrl+D), Preferences (Ctrl+,), Zoom to Selection (Shift+S), Ripple Delete in selected clips and in all tracks (also on Delete), Keyboard Shortcuts (Alt+K), Redo (Ctrl+Shift+Z), Crop (Ctrl+T), Add Cue Marker (F8), Insert Files (Ctrl+Shift+I), Paste to New (Ctrl+Alt+V), Mix Paste (Ctrl+Shift+V), Edit Original (Ctrl+E), New Audio File (Ctrl+Shift+N), Save As, Save All, Import (Ctrl+I), Export (Ctrl+Shift+E), Quit (Ctrl+Q), Save Selection As (Ctrl+Alt+S), Marquee, Lasso, Paintbrush and Healing Brush tools (E, D, P, B), Snapping (S), Split All Clips, Clip Gain (Shift+G), Show All Tracks (Alt+Shift+A), Hide Selected Tracks (Alt+H), Amplitude Statistics and Frequency Analysis (Ctrl+Alt+A, Ctrl+Alt+F), Trim to Time Selection (Alt+T), Previous and Next Edge (now Alt+Left and Alt+Right as in Audition; they were Ctrl+Left and Right), Range Marker (Ctrl+Shift+M), Noise Reduction process (Ctrl+Shift+P, our Noise Print Reducer).

Two of those are best guesses at which command Audition means: Range Marker and Noise Reduction (Ctrl+Shift+P). Export (Ctrl+Shift+E) opens our Session Mixdown. Zoom to Selection keeps Shift+/ and ? as well. In Audition Shift+/ is Zoom Selected Track instead; we have no such action yet.

## In Audition, no matching command here yet
Shuttle J, K, L; Play and Loop toggles (Ctrl+L); Pause (Ctrl+Shift+Space); Punch and Roll; Play only selected region and frequencies; set in and out points (I, O) and moving the playhead to them (Q, W); Adjust Selection commands; Move the playhead by sample, by page, to the previous and next clip edge (Alt+Left, Alt+Right as edge jumps are done) ; Jump to Time (Ctrl+J); Select Previous and Next Track (Up, Down in Multitrack); Track Visibility presets 1 to 5 (Shift+1 to 5, Shift+Alt+1 to 5 to save); Move Track Up and Down; Nudge by 5; Scroll left, right and by page; Clipboards 1 to 5 (Ctrl+1 to 5); Delete and Rename Marker, Delete All Markers; Toggle channels (Ctrl+B and the channel keys); Brush size and opacity ([, ]); Zoom to In and Out Points; spectral display and resolution keys; Panel shortcuts (Alt+0 to 9, Alt+Z, Alt+X, Ctrl+P); Minimize (Ctrl+M); Repair (Ctrl+U); Copy to New (Shift+Alt+C); Open recent file or session; Playback auto-scroll (A); Maximize panel (backtick).

## In our editor, not in Audition's list
Ctrl+F4 (second Close key), Ctrl+PageDown and Ctrl+PageUp (second next and previous file), Shift+Delete (second ripple delete key), Shift+M (CD track marker), the Up and Down arrows for the Waveform editor's left and right channel, Ctrl+F (Find), Ctrl+Alt+Left and Right as marker jumps where Audition's pair is the same (matched), Shift+\\ and | (Zoom Out Full variants), Ctrl+Shift+H variants, and the Shift+R and Ctrl+R pair as listed. These stay unless you ask to drop them.
