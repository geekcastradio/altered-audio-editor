# Altered Audio Editor 0.12.6

Libraries get easier to scan, and a few small editing gaps close.

- **Library bins start folded.** Open a bin to see its items. The bins you open stay open, and a search opens every bin so matches show. A library with only one section is never folded.
- **Library covers.** Pick a picture in a library, then choose "Use Selected Picture as Library Cover" from the Libraries menu. The cover replaces the initials badge in the panel header. "Remove Library Cover" clears it, and removing the picture from the library clears it too. The cover is saved inside the library, so it moves with the folder.
- **Repeat Last Command.** Edit > Repeat Last Command runs the last edit or effect again: Amplify, Normalize, the fades, Invert, Reverse, Silence, the generators, Crop, Mix Paste and clip operations such as Split, Merge and Trim. It never repeats a window, a save or playback. Effects that open a dialog open it again.
- **QuickPass.** Three more starting points: Keep Only the Loud Parts, Split Out Mic Bleed and Shorten a Lecture.
- **Favorites.** A fresh install starts with nine effects starred (Hum Cut, Noise Reducer, DC Offset, De-esser, Dynamics, Speech Leveler, Parametric EQ, Limiter and Pitch Shift). Your own stars replace the starter set as soon as you change anything.
