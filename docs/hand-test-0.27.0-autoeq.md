# Hand test: Match EQ to a neutral voice target (0.27.0)

1. Open a session with a spoken-word track. Select a stretch of speech with no music (a time selection keeps the measurement honest).
2. Effects > Match EQ. Set "Match to" to "Neutral voice target". The "To sound like" row goes away and the note changes.
3. Press Match. A short list of EQ bands appears and no band is bigger than 6 dB. Add EQ to Track. Listen with the EQ on and off: it should be a small, gentle change, not a different voice.
4. Repeat on a bright voice and a boomy voice. Report which way the suggestion moved each, and whether it sounded better. The target curve is a guess and I want your ears on it.
5. Switch "Match to" back to "Another track". The old result clears and the two-track match works as before.
6. With silence or music in the selection, the suggestion is worse. Report what you saw.
