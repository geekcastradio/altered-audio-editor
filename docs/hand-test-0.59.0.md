# Hand test: 0.59.0

Nothing should look or act differently. A quick pass:

- File > Export > Session Mixdown and Batch Convert: switch between WAV, FLAC, MP3, M4A and Opus. Each offers the same bit depths and shows the same size estimate and description as in 0.58.0. Open a saved export setting and check it comes back as saved.
- Open a clip in the Waveform editor and use the pitch tools: tune with a scale and strength, then a bend. The report sentence reads as before, and a setting that changes nothing is skipped.
- Help > Copy Bug Report Info: the text starts with the version, then the system line. Any Windows user name in a path shows as `<user>`.
- Welcome dialog: it still only shows on a fresh install or when an update adds a page. Nothing new appears on a normal start.
- Open, play, edit, save, close and reopen a session: nothing different from 0.58.0.
