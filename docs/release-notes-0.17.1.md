## Altered Audio Editor 0.17.1

A small fix release for 0.17.0, from testing.

### Fixes
- **Space bar** now pauses where playback is and resumes from there, whatever Return to Start on Stop is set to. That toggle (Transport menu, Shift+X) still decides what the Stop button does.
- **Middle-button drag** slides the timeline sideways only. Hold Shift to move up and down as well. The scroll wheel still scrolls the tracks.
- **Track header:** Sync Lock now sits next to M and S, so Mono and Invert Polarity are no longer pushed under the edge.
- **Clip names** sit lower and further in, so a selected clip's outline no longer cuts them off.
- **QuickPass** has a Cancel button while a scan runs, and a scan whose type you change is ignored instead of leaving the panel stuck.
- **Libraries:** a Details button under the list hides and shows the item details. It remembers your choice.
