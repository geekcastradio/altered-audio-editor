# Hand test for 0.61.0

Almost nothing user-facing changes. A short pass is enough.

1. Record volume automation on a track in each record mode. Points land where you expect and the lane glides back when you let go.
2. Open the effect list, star a few favorites, and adjust controls. Values stay in range and typed values parse.
3. Load each Curve EQ preset and check the curve looks sensible.
4. Save, apply and remove an effect preset. Banks sort in natural order (Preset 2 before Preset 10).
5. Open the Metadata panel: save and remove a tag set, and check year and track fields flag bad values.
6. Soundboard pads and Library bins: add, rename and recolor. Starter bins appear on a fresh library.
7. Batch Convert: add files twice (no repeats), try each naming mode with {name}, {number}, {date} and {format}, set a folder, and check the conflict warning when two files would write one name.
8. Batch Convert: save a chain, apply it, remove it, and try a built-in chain.
9. Help > Ask a Question or Share an Idea... opens the GitHub Discussions page in your browser.
10. Check the update notice and Help > Check for Updates still work.
