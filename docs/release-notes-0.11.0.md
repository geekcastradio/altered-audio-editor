# Altered Audio Editor 0.11.0

- **Hardware controllers.** Edit > Controllers lets a MIDI fader box or control surface (a Behringer BCF2000, a Mackie Control and the like) run track faders, pans, mute, solo, arm, the master and the transport. One button sets up the standard Mackie Control layout; anything else can be learned control by control. Faders work with the automation modes: Write, Latch and Touch record from a real fader, and a Mackie fader's touch sensor marks exactly when you grab and let go. Motorized faders do not follow the screen yet. Nothing is sent to the device.
