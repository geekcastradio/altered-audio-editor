# Hand test: four more dialogs on the shared shell (0.27.0)

For each: it opens with the right control focused, Escape closes it (except while it is measuring), a click outside closes it, Cancel or Close is on the left and the main action last.

1. File > Check Loudness. Pick a target, press Measure. While measuring, Escape and a click outside do nothing and Cancel stops it. After a measurement the cards show Pass, Close or Fix. Raise or Lower Master appears only when it is safe. Close is the left-most button. Try the broadcast target (region row appears) and the audiobook check (three cards).
2. Open Loudness Match from its menu, once with clips selected and once with whole tracks. Try each Match by choice: Peak, True Peak, RMS and Loudness. The Target row now shows only for Loudness. Level shows for the others. The table lists rows, red rows start unticked, the limiter checkbox ticks them. Apply to N items works.
3. File > Publish Package. Title is focused. Enter in the title does not close it unless the package can be made. Browse picks a folder. Format fields and the loudness scan still work. The three sections still read as sections. Make Package works.
4. File > Export > Session Mixdown. File name is focused and selected. Change... opens a small dialog over it: Escape closes only the small one, Enter closes only the small one. Sample type, Format settings and Mixdown options all work. Export works, Cancel and Escape do not export.
5. In all four, the buttons, fields and title bar match the dialogs from the earlier packs.
