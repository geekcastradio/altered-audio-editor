# Security policy

## Reporting a problem

Please don't open a public issue for a security problem. Use **Security → Report a vulnerability** on this repository (GitHub's private reporting). Include what you found, how to reproduce it, and which version.

You'll get a reply within a week. Fixes ship in the next release, and you'll be credited unless you'd rather not be.

## Supported versions

Only the latest release gets fixes while the project is in early development.

## Scope

The app makes no network calls on its own and has no accounts. Reports about file handling (opening crafted audio, session or zip files), the installer, and the update check (once it exists) are most useful.
