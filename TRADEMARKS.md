## The official version

The official Altered Audio Editor comes from one place: the [Releases page](https://github.com/geekcastradio/altered-audio-editor/releases) of `github.com/geekcastradio/altered-audio-editor`, published by The GeekCast Radio Network, LLC (The GCRN, thegcrn.com). Each release lists its files and a `SHA256SUMS.txt` so you can check your download. Updates inside the app come from the same releases page, signed with our key.

If you got the app from somewhere else, or a build uses the name but is not published on that page, it is not ours. We cannot vouch for it. A copy of the source on GitHub under another account is a fork, not the official project.

You may:
- Say your project is "based on Altered Audio Editor" or "a fork of Altered Audio Editor".
- Use the name to refer to this project accurately.

You may not, without written permission:
- Release a fork, build or derivative under the Altered Audio Editor name or logo, or a confusingly similar one.
- Use the name or logo in a way that suggests The GeekCast Radio Network, LLC made or endorses your version.

Fork freely; just give it its own name and icon.

A fork that sits on GitHub as a copy, a backup or a place to prepare a pull request can keep the default repository name. The rule applies when you release or distribute builds of a changed version.

## Launchers and app catalogs

Launchers, installers and app catalogs (ArtCraft Launcher is one example) are welcome to include Altered Audio Editor and to use its name and logo to identify it, on these terms:

- Offer the official release builds only, as published on this project's GitHub releases page, unmodified.
- Keep the app as we ship it: its own updater, its own settings and its own folders. Do not replace the updater, change where it stores settings, or add tracking, accounts, ads or bundled extras to it.
- Keep the license, the source offer and the notices that come with each build.
- Do not suggest that The GeekCast Radio Network, LLC runs, endorses or supports your launcher beyond listing the app.
- A build you changed in any way must be renamed and given its own icon. It may not use the Altered Audio Editor name or logo.

This permission is for listing the unmodified official app. It can be withdrawn for anyone who breaks these terms. Anything beyond it needs written permission from The GeekCast Radio Network, LLC.
